1 Introduction

Ce document sert à valider la conversion d’un fichier Markdown vers PDF avec plusieurs moteurs :

  • HTML + Chrome
  • HTML + WeasyPrint
  • LuaLaTeX (MiKTeX)

L’objectif est d’identifier les différences de rendu.
